# Financial Intelligence — web design system ("Cobalt Blueprint", v7.8)

The annual report as a poster you can pick up. Ink and bone, with full-bleed cobalt slabs and one 3D object: the company's fiscal years as columns. The data rules never change: one scale per chart, zero at the floor, exact values one click away, direction shown by ▲ ▼ and a sign as well as colour, nothing estimated presented as reported.

The live reference is the in-app brand kit at `/brand`.

## Mark

Three isometric columns rising left to right: three audited years, the newest in cobalt. The geometry lives in one place, `src/lib/brandMark.ts` (`MARK_COLUMNS`, `markFaces`, `markSvg`), and drives:

- the header logo and wordmark (`src/components/Logo.tsx`),
- the 3D logo on `/brand` (`src/components/three/Skyline.tsx` → `MarkScene`),
- favicons, PWA icons, the Open Graph card and `docs/social-preview.png`, all generated by `scripts/render-brand.mjs` (needs `npm run dev` running; set `PUPPETEER_CORE` and `BROWSER`).

Wordmark: "Financial" in Geist 800, "*Intelligence*" in Libre Caslon Condensed italic.

Inside a `.slab` the tokens are re-mapped (bone text, ink display type, bright up/down on ink pills), so components work unchanged on cobalt.

## Type

- **Geist** 780–850 for titles and figures, tight tracking (−0.05 to −0.07 em); tabular, lining figures everywhere.
- **Libre Caslon Condensed italic** for one editorial phrase per headline.
- **Geist Mono** for labels, tickers, dates and indices.
- **Doto** for the fiscal-year readout in the hero.

## 3D

| Scene | Where | Interaction |
|---|---|---|
| Skyline | Overview hero | Each fiscal year is an ink column on a blueprint grid; height = reported value on one scale, losses below the floor, unreported years as ghosts. Drag sideways to turn (springs back on release), tap a column or use the year rail / arrow keys to select; the selected column turns bone and hops. |
| Mark | `/brand` | Flick to spin with inertia, tap to make the columns jump. |

Rules: three.js loads lazily (`Scene3D.tsx`) only when a scene is on the page and WebGL exists; otherwise the flat fallback renders (scrub-able bars in the hero, the SVG mark on `/brand`), also if the GPU context fails mid-session. Phones and touch screens get pixel ratio ≤ 1.4, no contact shadows and no pointer parallax. Scenes stop rendering when off screen or when the tab is hidden. Canvases use `touch-action: pan-y`, so vertical scrolling always works. Reduced motion: no idle sway, columns appear at full height, the turntable stays put.

## Interaction

| Pattern | Where |
|---|---|
| ⌘K / Ctrl+K / `/` command palette — company search + page jump | everywhere |
| Cobalt nav pill slides between pages (`layoutId`); full-screen cobalt menu below 1300 px | masthead |
| Page titles spring in word by word, with a "03 / 10" index tile | page headers |
| KPI tiles: pull and release with a **mouse only** (touch always scrolls), count-up, hover lift and cobalt rule | KPI strips |
| Year rail with a sliding pill; metric pill | Overview hero |
| Press ripples from the pointer on every button-like control | everywhere |
| Swatches copy their hex with a squash and a toast | `/brand` |
| Building-columns loader; columns that slump in empty and error states | states |

Built with `motion` (`<MotionConfig reducedMotion="user">`) plus CSS media queries; everything decorative stops under `prefers-reduced-motion`.

## Layout

Max width 1360 px. KPI strip 6 → 3 (under 1180 px) → 2 (under 768 px). Wide tables scroll inside their own region with edge shadows. Checked at 1440, 768 and 390 px in both themes, with WebGL, without WebGL and with reduced motion; no horizontal overflow.
